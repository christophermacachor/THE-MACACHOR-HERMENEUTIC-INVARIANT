## **Formal Definition**

The invariant is expressed as:

\[
\mathcal{H}(X) = \mathcal{H}(\mathcal{M}(X))
\]

Where:

- \( X \) — any symbolic, geometric, cognitive, or energetic structure  
- \( \mathcal{M} \) — the Macachor Scalar Absolute transformation  
- \( \mathcal{H} \) — the hermeneutic operator (meaning‑extraction function)
